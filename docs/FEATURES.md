# Product Features

## Coding practice

Users can browse problems, write solutions in an in-browser editor, run code against visible examples, and submit against hidden test cases. Submission history makes previous attempts and outcomes easy to review.

## Contests

Administrators can assemble contests from existing problems and configure their schedule. The platform distinguishes upcoming, live, and completed events, blocks late submissions, and ranks participants by score and tie time.

## Learning support

Problems can include Cloudinary-hosted video editorials. An AI assistant powered by Gemini helps users reason through doubts while they practice.

## Dashboard

The user dashboard summarizes solved problems, difficulty-level progress, recent submissions, and contest participation.

## Administration

Role-protected tools support problem creation and updates, contest management, and video editorial administration.

## Premium membership

Razorpay handles checkout. The backend verifies payment ownership, amount, currency, signature, and single-use status before enabling premium access.
